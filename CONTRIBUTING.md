# Contributing to Alejandro

This is a personal fork. Open an issue in [Alejandro](https://github.com/Alejandro-Valadez/alejandro/issues) to discuss changes.

Keep changes focused, preserve existing provider and remote-environment behavior, and run `vp run check:changed` before pushing. See [AGENTS.md](./AGENTS.md) and the [development runbook](./docs/operations/development.md) for repository conventions.

Retain the original license and copyright notices when adapting upstream code or borrowing from another project.
